# Memory-bank index

Historical design context retained for repository archaeology. These files are
not current task state or production runbooks.

## Durable context

- [projectbrief.md](projectbrief.md) — original project scope.
- [productContext.md](productContext.md) — original users and value model.
- [systemPatterns.md](systemPatterns.md) — recurring infrastructure patterns.
- [techContext.md](techContext.md) — historical technology context; verify every
  version and service claim against current code.

## Evidence archives

- [`archive/`](archive/) — completed feature records.
- [`reflection/`](reflection/) — implementation retrospectives.

Completed active-context, progress, and task journals were removed because they
duplicated these archives and falsely appeared current. Git history remains the
source for deleted journal detail.
