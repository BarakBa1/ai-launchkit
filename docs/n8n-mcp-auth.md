# n8n-MCP authentication

The optional `n8n-mcp` Compose profile requires two different credentials:

- `N8N_MCP_TOKEN` authenticates inbound MCP HTTP clients and may be generated by
  `scripts/03_generate_secrets.sh`.
- `N8N_API_KEY` authenticates the MCP server to n8n's public API. Copy a public
  API JWT issued in n8n under Settings -> API. It is never generated by this
  repository.

When `n8n-mcp` is selected, the generator and service-selection wizard fail
closed unless `N8N_API_KEY` has JWT syntax and its payload audience is
`public-api`. The checks do not print the supplied value and cannot verify its
signature; issuance and revocation remain n8n responsibilities. A blank
`N8N_API_KEY` remains valid when `n8n-mcp` is not selected.

If validation fails, set the value in the runtime `.env` from n8n's API-key
settings and rerun the wizard. Never paste either credential into logs,
documentation, or source control. Compose keeps the two values mapped to
separate environment variables in the `n8n-mcp` service.
